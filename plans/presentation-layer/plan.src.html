Hard to undo

4 things the plan locks in

Every answer is {serverNow, data} or {serverNow, error}

Both the page and your teammate's core depend on this shape. serverNow is how countdowns follow the server clock (locked decision 2).

13 paths, M-01 to M-13

Written in docs/09-web-api.md. ApiContractTest checks each one. The same test must pass when the real core is plugged in.

The token travels in the screen address

For example #/queue/the-1975/Q-1001. The server returns myToken on reopen, so the browser stores nothing. This replaces the spec's localStorage line (Task D updates it).

Maven, Java 17, Javalin 6.3.0

Your teammate's core/ uses the same pom.xml. Maven is not installed on this Mac yet. Task 1 installs it with Homebrew.

Worth knowing

Things the plan decided for you

Added beyond the spec

  • /dev/advance jumps the fake clock so screenshots do not wait 10 real minutes
  • Every answer also carries clockRate so countdowns follow the fake's ×10 or ×100 clock
  • Reply records live in 2 files, Views.java and Requests.java instead of 1 file each
  • The QR is a look-alike pattern (not scannable). The signed payload is real text

Left as is

  • The story event is now The 1975 Bangkok in every doc (was BLACKPINK, switched on 10 Oct)
  • The organizer console, SCR-30 to SCR-40 (a later spec)
  • Swipe between tickets (dots work instead)
